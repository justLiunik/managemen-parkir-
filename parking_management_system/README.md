# Parking Management System

Sistem manajemen parkir berbasis Python yang menggunakan basis data MySQL untuk melacak kendaraan yang masuk dan keluar, mengelola lama parkir, dan menyimpan informasi kendaraan beserta gambar.

## Features

- Catat Kendaraan Masuk: Mendaftarkan kendaraan baru yang masuk ke area parkir dengan nomor plat, jenis kendaraan, dan gambar opsional
- Catat Kendaraan Keluar: Menandai kendaraan sebagai telah keluar dan secara otomatis menghitung lama parkir
- Tampilkan Daftar Kendaraan: Menampilkan semua kendaraan beserta riwayat parkirnya
- Pencarian Kendaraan: Mencari kendaraan tertentu berdasarkan nomor plat
- Statistik Parkir: Menampilkan statistik real-time area parkir
- Pengelolaan Kendaraan: Menghapus catatan kendaraan dari basis data
- Penyimpanan Gambar: Menyimpan gambar kendaraan di basis data
